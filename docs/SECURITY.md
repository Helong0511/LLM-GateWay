# 安全说明

本文件只记录已经落地的控制，以及尚未验证的项。扫描通过不等于安全。

## 已落地

- 生产环境拒绝 mock 支付、演示模型、带 `dev-only` / `change-me` / `forge-dev-only` 的会话密钥、加密主密钥、数据库连接串和 LiteLLM master key。
- 日志脱敏覆盖密码、Bearer、Cookie、`sk-` 密钥、邮箱局部打码、PEM 私钥和助记词字段。未处理异常只记录异常类型。
- 统一错误响应不返回堆栈。参数校验错误不回显原始输入。
- 请求体按 Content-Length 限制为 4MB。
- `/api/meta` 不返回密钥字段。
- 会话令牌和邮件令牌的表结构只保存 SHA-256。当前还没有签发逻辑。
- 数据库和 Redis 的开发端口只绑定 127.0.0.1。生产编排不发布这两个端口。
- BFF 拒绝 `.`、`..` 和带斜杠的路径段。
- OpenAPI 文档在生产环境关闭。

## 密钥

`.env` 不入库。示例文件里的开发口令不能用于生产。加密主密钥还没有用来加密数据；在第一次写入密文之前轮换它没有历史包袱，之后轮换必须先停下来做重加密方案。
