## 风险

1. 没有 Docker，PostgreSQL、Redis、Mailpit、LiteLLM 和 Nginx 都没有在本机拉起。`/readyz` 在依赖缺失时会返回 503，这是预期行为，不能当成栈已就绪。
2. LiteLLM v1.106.5 的版本和许可证已按官方发布说明核对，镜像没有在本机拉取。
3. 默认海外模式只是配置声明。Stripe、USDT 网关、真实邮件和上游模型密钥都还没有，也不能用 mock 结果冒充。
4. 生产口令、主密钥和支付密钥都还是示例值。`.env.example` 里的 `dev-only` 标记会被生产启动校验拒绝。
