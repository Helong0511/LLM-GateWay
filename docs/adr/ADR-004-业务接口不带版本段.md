# ADR-004：业务接口不带版本段

## 状态

已接受。2026-10-28。

## 背景

需求 §12 写的业务前缀是 `/api/v1`。实施时要求所有业务路由不再使用 `v1` 这种版本段。

## 决定

业务接口直接使用 `/api/...`，例如 `/api/meta`、`/api/auth/login`、`/api/admin/whoami`。浏览器只访问本站的 `/api/*`，BFF 把存活和就绪探针原样转到 `/healthz`、`/readyz`，其余路径补上后端的 `/api` 前缀。路径里出现 `v1` 段时，BFF 直接返回 400。

公开模型调用仍保留 OpenAI 协议路径 `/v1/chat/completions`、`/v1/models`、`/v1/embeddings`。这是上游客户端约定的协议路径，不是本平台的版本号。Nginx 的 `location /v1/` 只为这条链路预留，当前还没有实现转发逻辑。

`docs/软件需求.MD` 保持原文。本决定以 ADR 记录偏差。
